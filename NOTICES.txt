Apple: https://developer.apple.com/documentation/metal/performing-your-own-tone-mapping
Light Up My Life: https://github.com/ben4mn/light-up-my-life
Reference commit: a639d76643a167f6a63f023c025cc530ee03db7d

Additional implementation references (API usage and compositing concepts; not vendored):
https://github.com/niklasr22/BrightIntosh/blob/main/BrightIntosh/UI/Overlay.swift
https://github.com/starkdmi/BrightXDR/blob/main/BrightXDR/MetalView.swift
These references show attaching the multiply filter directly to the CAMetalLayer.

Version 1.5 replaces the full-screen multiply overlay with a 256-entry
CoreGraphics display transfer table and a one-pixel ordinary EDR surface.
API/technique references, independently implemented in SunLift:
https://developer.apple.com/documentation/coregraphics/cgsetdisplaytransferbytable(_:_:_:_:_:)
https://github.com/niklasr22/BrightIntosh/blob/main/BrightIntosh/GammaTechnique.swift
https://github.com/niklasr22/BrightIntosh/blob/main/BrightIntosh/OverlayWindow.swift
No source files from those projects are bundled. The preceding MIT attribution
is retained for the earlier rendering implementation used by SunLift.
