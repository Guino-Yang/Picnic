## English

Autumn is picnic season. Work still needs my MacBook, though, so I guess it’s coming along. 🧺💻

A warm drink, a cool breeze… and a screen that’s a little hard to see in the sun.

That’s why I made **Picnic**: a little extra screen brightness for working in the sunshine. My first GitHub project, made for a little more time outside. 🌱

- ☀️ **Follows the light.** Automatically switches between a gentle 1.5× and a brighter 2× boost. Two sliders let you decide when each kicks in.
- 🧺 **A tiny basket in your menu bar.** It fills in when the boost is on, and quietly waits when it isn’t.
- ⌨️ **Your usual brightness keys.** Adjust brightness as always. Quit Picnic, and the extra boost goes away.

**[Download Picnic →](https://github.com/Guino-Yang/Picnic/releases)**

Unzip, move `Picnic.app` to Applications, and open the little basket in your menu bar. Enable “登录时启动” (Launch at login) if you’d like it to come along every day.

<details>
<summary>A little note before you pack</summary>

For Apple Silicon MacBook built-in displays, on macOS 14 or later. This is an experimental release, currently tested on a 14-inch M1 Pro MacBook Pro. The download is not Apple-notarized, so macOS may block it.

[Setup, compatibility & building from source](docs/GUIDE.md) · [Report an issue](https://github.com/Guino-Yang/Picnic/issues)

</details>

## 日本語

秋はピクニックの季節。でも、仕事には MacBook が欠かせない。なら、MacBook も連れていこう。🧺💻

温かい飲み物と、ひんやりした風。気持ちいいけれど、日なたでは画面がちょっと見えにくい。

そんな日のために作ったのが **Picnic**。画面に明るさを少し足して、外で過ごす時間をもう少し。私にとって初めての GitHub プロジェクトです。🌱

- ☀️ **周りの明るさに合わせて。** やさしい 1.5× と、明るめの 2× を自動で切り替え。どのくらい明るくなったら切り替えるかを、2つのスライダーで調整できます。
- 🧺 **メニューバーに、小さなバスケット。** 明るさを上げている間は塗りつぶしに。それ以外は、そっと待機します。
- ⌨️ **明るさの調整は、いつもどおり。** 普段の明るさキーがそのまま使えます。Picnic を終了すれば、いつもの明るさに戻ります。

**[Picnic をダウンロード →](https://github.com/Guino-Yang/Picnic/releases)**

解凍した `Picnic.app` を「アプリケーション」に入れて起動し、メニューバーのバスケットをクリック。毎日一緒に起動したいときは、メニューの「登录时启动」をオンにしてください。

<details>
<summary>出かける前に、ひとつだけ</summary>

Apple Silicon 搭載 MacBook の内蔵ディスプレイ向け。macOS 14 以降が対象で、現在は14インチ M1 Pro MacBook Pro で動作確認しています。試験公開版で Apple の公証は受けていないため、macOS に起動をブロックされる場合があります。

## 简体中文

秋天是适合野餐的季节，但工作又离不开 MacBook。那就把它也带上，在阳光下工作吧。🧺💻

一杯热饮，一点凉风。唯一的小麻烦是，屏幕在太阳底下有点看不清。

于是有了 **Picnic**，给屏幕添一点亮，让工作也能晒晒太阳。这是我的第一个 GitHub 项目，想让待在户外的时间再多一点。🌱

- ☀️ **跟着阳光，慢慢变亮。** 在柔和的 1.5× 和更明亮的 2× 之间自动切换，两个滑块决定什么时候开启。
- 🧺 **菜单栏里的一只小篮子。** 增强时变成实心，平时就安安静静地待着。
- ⌨️ **还是熟悉的亮度键。** 像平常一样调节亮度；退出 Picnic，就会撤掉额外的增强。

**[下载 Picnic →](https://github.com/Guino-Yang/Picnic/releases)**

解压后把 `Picnic.app` 放进「应用程序」，启动后点开菜单栏的小篮子。想每天一起出发，就勾选「登录时启动」。
