# Changelog

## 2.0.0 — 2026-10-25

First public release. Earlier version numbers refer to local development iterations.

- Automatic ambient-light tiers: 1.5× and 2×, with independent 250 lx threshold sliders.
- Three-second activation and five-second release hysteresis, with a two-second gain ramp.
- Native menu bar basket outline / filled state icons.
- Built-in display only; system brightness controls remain available.
- Native login item and automatic mode on normal launch.
- Picnic basket and sun app icon.
- 97 policy and output-table checks, plus documented real-device validation.

The app is experimental, ad-hoc signed, and not notarized. Gain values are not calibrated physical luminance multipliers.
